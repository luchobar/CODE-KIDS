HTML: El Esqueleto de la Web 🏗️

Estructura y etiquetas fundamentales

📝 Pendiente

💡 Concepto

HTML (HyperText Markup Language) es el lenguaje que da estructura a las páginas web. Piensa en él como el esqueleto de una casa.

Estructura básica:

<!DOCTYPE html>
<html>
  <head>
    <title>Mi Primera Página</title>
  </head>
  <body>
    <h1>¡Hola Mundo!</h1>
    <p>Este es mi primer sitio web</p>
  </body>
</html>

💡 ¿Qué es CSS?

                    
CSS (Cascading Style Sheets) es el lenguaje que da estilo y diseño a las páginas web. Si HTML es el esqueleto, CSS es la ropa y el maquillaje.
