¿Qué es un Algoritmo? 🤔

Secuencias de pasos para resolver problemas

📝 Pendiente

💡 Concepto

Un algoritmo es como una receta de cocina: una serie de pasos ordenados para resolver un problema o completar una tarea.

Ejemplo: Algoritmo para lavarse los dientes

  1. Tomar el cepillo de dientes
  2. Poner pasta dental en el cepillo
  3. Abrir la llave del agua
  4. Mojar el cepillo
  5. Cepillar los dientes por 2 minutos
  6. Enjuagar la boca
  7. Guardar el cepillo

Variables (Leer y Escribir) 📦

Cajas para guardar información

🔒 Bloqueada

💡 Concepto

Una variable es como una caja donde guardamos información que puede cambiar. Tiene un nombre y un valor.

Algoritmo SaludarPersona
    Definir nombre Como Caracter
    Escribir "¿Cuál es tu nombre?"
    Leer nombre
    Escribir "¡Hola, ", nombre, "!"
FinAlgoritmo

Decisiones (Si-Entonces) 🔀

Enseñando a pensar a tu programa

🔒 Bloqueada

💡 Concepto

Las decisiones permiten que el programa tome diferentes caminos según una condición.

Si edad >= 18 Entonces
    Escribir "Eres mayor de edad"
Sino
    Escribir "Eres menor de edad"
FinSi

Bucles (Para, Mientras) 🔄

Repitiendo acciones automáticamente

🔒 Bloqueada

💡 Concepto

Los bucles permiten repetir acciones sin escribir el mismo código muchas veces.

Para i <- 1 Hasta 5 Con Paso 1 Hacer
    Escribir "Número: ", i
FinPara
